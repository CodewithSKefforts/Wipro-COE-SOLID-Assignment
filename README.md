# Wipro COE Milestone-1: SOLID Principles Assignment

This repository contains C# practical implementations demonstrating all five **SOLID Principles** and the **Strategy Design Pattern**.

## Contents
- **Practical 1 (`Practical1_SRP.cs`):** Student Management System — Single Responsibility Principle (SRP)
- **Practical 2 (`Practical2_OCP.cs`):** Discount Management — Open/Closed Principle (OCP)
- **Practical 3 (`Practical3_LSP_ISP.cs`):** Bird Management — Liskov Substitution (LSP) & Interface Segregation Principle (ISP)
- **Practical 4 (`Practical4_DIP_Strategy.cs`):** Payment Management — Dependency Inversion Principle (DIP) & Strategy Pattern
- **Practical 5 (`Practical5_SOLID.cs`):** Notification Management — Combined implementation of all 5 SOLID Principles
- **Driver Code (`Program.cs`):** Console entry point to execute and test all practicals
